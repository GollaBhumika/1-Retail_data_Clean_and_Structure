# Retail Sales Data Cleaning

## Project Overview
This project focuses on cleaning and structuring a retail sales dataset using Python and Pandas. The objective is to improve data quality and prepare the dataset for further analysis.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- GitHub

## Dataset Overview
- Rows: 9,800
- Columns: 18
- Missing values: 11 in `Postal Code`
- Exact duplicate rows: 0

## Data Cleaning Steps
1. Loaded and inspected the dataset.
2. Checked missing values and duplicate records.
3. Converted order and shipping dates to datetime.
4. Standardized column names.
5. Reviewed data types and validated date logic.
6. Preserved missing postal codes pending verification.

## Project Structure
- `data/raw/` — Original dataset, subject to dataset licensing.
- `data/cleaned/` — Cleaned dataset.
- `notebooks/` — Data cleaning notebook.

## Key Learning
Practiced data quality checks, missing-value analysis, date conversion, data type handling, and preparing datasets for analysis.
